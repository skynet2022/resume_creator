# رزومه تعاملی فارسی — محمدرضا واحدی

رزومه وب‌محور کاملاً فارسی (راست‌به‌چپ) برای توسعه‌دهنده وب و برنامه‌های کاربردی، با امکان ویرایش مستقیم و خروجی PDF.

## امکانات

- **ویرایش زنده:** روی هر متن کلیک کنید و ویرایش کنید — تغییرات خودکار در localStorage مرورگر ذخیره می‌شود
- **حالت ویرایش:** دکمه «حالت ویرایش» — نمایش دکمه‌های حذف و افزودن برای سوابق، پروژه‌ها، مهارت‌ها و ...
- **آپلود تصویر پروفایل:** در حالت ویرایش روی اواتار کلیک کنید تا از گالری عکس بگذارید
- **گیج‌های قابل درگ:** با کشیدن گیج‌های مهارت به بالا/پایین، مقدار را کم و زیاد کنید
- **خروجی PDF استاندارد A4:** دکمه «چاپ / خروجی PDF» → مقصد Save as PDF + تیک Background graphics
- **فونت وزیر (Vazirmatn):** به‌صورت آفلاین داخل فایل جاسازی شده — بدون وابستگی به CDN
- **المان‌های بصری:** نمودار گیج، نمودار راداری، دیاگرام تفکر سیستمی، جدول پروژه‌ها، تایم‌لاین، آمار

## اجرا

فایل `resume.html` را مستقیم در مرورگر باز کنید یا با یک سرور ساده:

```bash
python3 -m http.server 8123
```

سپس به `http://localhost:8123/resume.html` بروید.

## تکنولوژی

تک‌فایل HTML + CSS + JavaScript (بدون وابستگی خارجی — فقط فونت جاسازی‌شده).
